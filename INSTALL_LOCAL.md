# 🎤 Руководство по локальной установке Discord Голосового Бота «Кирилл» (с большой Vosk-моделью)

Данный репозиторий содержит **Discord голосового бота «Кирилл»** на Node.js с интегрированным искусственным интеллектом и локальным офлайн-распознаванием речи Vosk. 

В этом руководстве подробно описано, как запустить и настроить голосового бота на вашем домашнем компьютере под управлением **Windows** с высокоточной большой моделью Vosk.

---

## 📋 Системные требования

*   **Операционная система:** Windows 10 / 11 (64-bit)
*   **Оперативная память (RAM):** минимум 8 ГБ (рекомендуется 16 ГБ или более для плавной работы Vosk-модели весом 3.5 ГБ)
*   **Свободное место на диске:** ~6 ГБ

---

## 🛠️ Шаг 1. Установка необходимых компонентов

### 1. Установка Node.js
1. Скачайте и установите **Node.js** (LTS-версию, например v20+) с официального сайта: [nodejs.org](https://nodejs.org/).
2. Установите со всеми настройками по умолчанию.

### 2. Установка Python
1. Скачайте установщик Python (рекомендуется версия **3.10** или **3.11**) с сайта: [python.org](https://www.python.org/downloads/).
2. **ВАЖНО**: При запуске установщика обязательно поставьте галочку **`Add python.exe to PATH`** в самом низу окна!

### 3. Установка и настройка FFmpeg
FFmpeg необходим боту для конвертации Opus/PCM аудио в формат WAV.
1. Скачайте сборку FFmpeg для Windows: [gyan.dev](https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-essentials.7z).
2. Распакуйте архив и переименуйте папку в `ffmpeg`. Положите её в корень диска `C:\`, чтобы путь был: `C:\ffmpeg`.
3. Добавьте FFmpeg в переменные среды Windows (PATH):
   * Нажмите клавишу `Win`, введите **«Изменение системных переменных среды»** и откройте.
   * Нажмите кнопку **«Переменные среды...»** внизу окна.
   * В разделе «Системные переменные» найдите строку **`Path`**, выберите её и нажмите **«Изменить...»**.
   * Нажмите **«Создать»** справа и введите путь к исполняемым файлам: **`C:\ffmpeg\bin`**.
   * Нажмите «ОК» во всех окнах, чтобы сохранить изменения.

---

## 🎤 Шаг 2. Скачивание большой Vosk-модели

1. Перейдите на сайт моделей Vosk: [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models).
2. Скачайте большую модель для русского языка: **`vosk-model-ru-0.42`** (~1.8 ГБ в архиве zip).
3. Создайте в корне проекта (в этой же папке) папку **`data`**.
4. Распакуйте архив в созданную папку так, чтобы путь к модели выглядел так:
   `C:\Projects\voice_bot\data\vosk-model-ru-0.42\am\model` (и другие файлы модели).

---

## ⚙️ Шаг 3. Настройка токена голосового бота

Создайте в папке проекта файл **`.env`** и пропишите туда токен вашего Discord-бота:
```text
DISCORD_TOKEN=ВАШ_ТОКЕН_ДИСКОРД_БОТА
```

*Примечание: Бот также использует DAVE (End-to-End Encryption) и поддерживает автоматический обход багов RTC-подключения.*

---

## 📦 Шаг 4. Установка зависимостей

Откройте консоль (CMD или PowerShell) в папке проекта и выполните по очереди команды:

### 1. Установка Node.js зависимостей
```bash
npm install
```

### 2. Настройка виртуального окружения Python для ML-обработки
```bash
# Создаем виртуальное окружение venv_voice
python -m venv venv_voice

# Активируем его
venv_voice\Scripts\activate

# Устанавливаем библиотеки для распознавания речи, синтеза голоса и ИИ
pip install vosk gtts g4f pillow paramiko
```

---

## 🚀 Шаг 5. Запуск голосового бота

Убедитесь, что в файле `process_audio.py` на строке 27 указан верный путь к вашей большой модели:
```python
model_path = "data/vosk-model-ru-0.42"
```

Для запуска бота выполните в консоли команду:
```bash
node voice_bot.js
```

---

## 👾 Использование в Discord

1. Позовите бота в ваш голосовой канал с помощью команды `!join` в любом текстовом канале.
2. Произнесите фразу, начинающуюся с триггера, например: **«Кирилл, расскажи шутку про Доту»** или **«Кирилл, как дела?»**.
3. Бот запишет ваш голос, распознает его с помощью Vosk, сгенерирует ответ через нейросеть и озвучит его вам обратно в голосовой канал!
4. Для отключения бота используйте команду `!leave`.
