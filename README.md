# Alice Music & Voice AI Discord Bot

Это голосовой ИИ-ассистент "Алиса" с поддержкой воспроизведения музыки через SoundCloud.

## Требования

- Node.js v16+
- Python 3.8+
- Установленные пакеты Python (`vosk`, `g4f`, `gtts`, `pydub`, `pyaudio`)
- Модель Vosk (например, `vosk-model-small-ru-0.22`)
- Установленный `ffmpeg` в системе.

## Запуск

1. Переименуйте `.env.example` в `.env` и впишите токен вашего бота Discord.
2. Проверьте правильность путей к `python` и модели `vosk` в файлах `index.js` и `process_audio.py`.
3. Запустите бота:
   ```bash
   node index.js
   ```

## Использование

- `!join` - пригласить бота в ваш голосовой канал.
- `!leave` - отключить бота.
- `!play <название>` - поиск и включение музыки (SoundCloud).
- `!stop` - остановить музыку.
- `!skip` - пропустить текущий трек.

**Голосовые команды:**
- Скажите "Алиса, включи музыку [имя трека/исполнитель]", чтобы бот включил трек.
- Любые другие вопросы, начинающиеся с имени "Алиса", будут переданы ИИ для генерации ответа.
