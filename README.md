# 🎤 Discord Voice AI Assistant «Кирилл» (с распознаванием речи Vosk)

Премиальный Discord-бот на Node.js и Python, работающий как голосовой ИИ-помощник. Бот умеет подключаться к голосовому каналу, слушать вашу речь в реальном времени, распознавать её полностью офлайн с помощью движка **Vosk**, генерировать интеллектуальные и веселые ответы через ИИ-модели и озвучивать их вам обратно!

---

## ✨ Основные возможности

*   🎙️ **Офлайн-распознавание речи (Vosk):** Бот не использует платные облачные API для перевода речи в текст, а осуществляет распознавание речи прямо на вашей машине с помощью встроенной библиотеки Vosk (поддерживается как сверхлегкая модель 88 МБ, так и высокоточная модель 3.5 ГБ).
*   💬 **Интеграция с ИИ (GPT):** Ответы генерируются на лету с использованием ИИ-моделей (GPT-4o, GPT-4o-mini и др.) с настроенным системным промптом (бот общается с юмором, отвечает кратко и по делу на русском языке).
*   🔊 **Синтез речи (TTS):** Сгенерированный ответ мгновенно преобразуется в естественную человеческую речь (с помощью библиотеки gTTS) и транслируется прямо в голосовой канал Discord.
*   🛡️ **Безопасность DAVE (E2EE):** Архитектура бота поддерживает сквозное шифрование DAVE в голосовых каналах Discord и умеет автоматически переходить в passthrough-режим для бесперебойного приема аудиопотоков.
*   ⚡ **Автоматический обход сетевых зависаний:** Внедрен фикс принудительного IPv4-разрешения, предотвращающий зависание бота в статусе «RTC Connecting» на серверах с некорректно настроенным IPv6.

## 🛠️ Быстрый старт

Полное руководство по локальной настройке и установке на домашний компьютер под управлением Windows находится в файле **[INSTALL_LOCAL.md](INSTALL_LOCAL.md)**.

### Краткая инструкция по запуску:
1. Установите зависимости Node.js: `npm install`
2. Создайте виртуальное окружение Python и установите зависимости:
   ```bash
   python -m venv venv_voice
   venv_voice\Scripts\activate
   pip install vosk gtts g4f pillow paramiko
   ```
3. Скачайте модель Vosk и положите её в папку `data/`.
4. Создайте файл `.env` и впишите туда `DISCORD_TOKEN=ваш_токен_бота`.
5. Запустите бота командой: `node voice_bot.js`

## 👾 Список команд в Discord

*   `!join` — позвать бота в ваш текущий голосовой канал. Бот подключится, поприветствует вас голосом и перейдет в режим прослушивания.
*   `!leave` — отключить бота от голосового канала.
*   **Голосовой триггер «Кирилл»** — находясь в канале с ботом, начните фразу с обращения по имени (например: *«Кирилл, подскажи контрпик для Снайпера»*). Бот автоматически вырежет ваше обращение, передаст запрос ИИ и озвучит ответ.
